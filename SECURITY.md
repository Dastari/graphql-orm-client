# Security

Report a vulnerability privately, through this repository's
[Report a vulnerability](https://github.com/Dastari/graphql-orm-client/security/advisories/new) form. Don't open a
public issue, pull request or discussion about it.

Include the version, what an attacker needs (for example, control of one subgraph), and a reproduction if you have one.
A vulnerability in graphql-orm or its router belongs to [graphql-orm](https://github.com/Dastari/graphql-orm/security)
instead.

The package is pre-1.0. Fixes go into the next release; older pre-releases aren't patched.
